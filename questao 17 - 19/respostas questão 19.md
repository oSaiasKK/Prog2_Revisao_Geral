# Qual URL foi utilizada?
`https://restcountries.com/v3.1/name/{nome_do_pais}`
*(Exemplo aplicado: `https://restcountries.com/v3.1/name/Brazil`)*

# Qual método HTTP foi utilizado?
O método **GET**, utilizado para solicitar a recuperação de recursos/dados de um servidor.

# Qual código HTTP representa uma requisição bem-sucedida?
O código **`200 OK`** (indicando que a requisição foi processada e bem-sucedida).

# Em qual formato os dados foram recebidos?
No formato **JSON** (*JavaScript Object Notation*).

# Qual é a diferença entre uma requisição e uma resposta HTTP?
* **Requisição (Request):** É a mensagem enviada pelo cliente (geralmente o navegador) 
para o servidor, contendo o método, os cabeçalhos e a URL desejada.

* **Resposta (Response):** É a mensagem enviada de volta pelo servidor para o cliente após processar a requisição, 
contendo o código de status HTTP, os cabeçalhos de resposta e os dados solicitados (corpo da resposta).
